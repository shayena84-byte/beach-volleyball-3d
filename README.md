# Песок & Тактика — интерактивный 3D пляжный волейбол

Интерактивная 3D-тренировка: выход пасующего в «крест» до приёма, доводка мяча в «++» перед принимающим у сетки, высокая передача в зону 4 и прямолинейный разбег нападающего из-за левой боковой линии.

## Возможности

- Трёхмерная пляжная площадка, сетка, мультяшные анимированные игроки.
- Мяч с процедурной текстурой в цветах Mikasa BV550C-WYBR (учебная визуализация, не официальный 3D-ассет).
- Семь этапов розыгрыша, ползунок времени, воспроизведение, пауза и выбор скорости.
- Свободное вращение и масштабирование камеры, ракурсы «Обзор», «Сверху», «Сбоку».
- Подписи на русском языке, переключатель траекторий, адаптация под смартфон.

## Запуск и GitHub Pages

Это статический сайт на HTML, CSS и JavaScript с Three.js 0.160.1 через jsDelivr. Сборка не требуется; нужен интернет для загрузки библиотеки.

Для локального просмотра запустите в каталоге сайта:

```bash
python3 -m http.server 8080
```

Для GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

После публикации страница будет доступна по адресу:
https://shayena84-byte.github.io/beach-volleyball-3d/

«Крест» и «++» — тренировочные ориентиры, а не официальные зоны площадки. Mikasa — товарный знак правообладателя; проект с производителем не связан.
